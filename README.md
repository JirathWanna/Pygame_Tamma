# Pygame_Tamma (แยกไฟล์)

## โครงสร้าง
- `main.py` — หน้าล็อบบี้, เมนู, กาชา และเชื่อมหน้าต่าง ๆ
- `battle.py` — เลือกด่าน, คลาส `Unit`, ระบบต่อสู้
- `team.py` — หน้าจัดทีมและฟังก์ชันแสดงตัวละคร
- `game_data.py` — ค่ากลาง, ข้อมูลตัวละคร/ด่าน, โหลด assets และฟังก์ชันวาด UI ที่ใช้ร่วมกัน
- `assets/` — ให้นำโฟลเดอร์ assets เดิมของเกมมาไว้ข้างไฟล์ Python ทั้ง 4 ไฟล์

## วิธีรัน
เปิด Terminal ในโฟลเดอร์นี้ แล้วรัน:
```bash
python main.py
```
ถ้าเครื่องยังไม่มี Pygame:
```bash
python -m pip install pygame
```

## ข้อตกลงการทำงานเป็นทีม
- คนดูแลระบบหลักแก้ `main.py`
- คนดูแลระบบต่อสู้แก้ `battle.py`
- คนดูแลจัดทีม/ตัวละครแก้ `team.py`
- `game_data.py` เป็นไฟล์กลาง ควรตกลงกันก่อนแก้ เพราะทุกระบบนำข้อมูลจากไฟล์นี้ไปใช้
- ทุกคนต้องมีไฟล์ทั้ง 4 ไฟล์และโฟลเดอร์ `assets/` ในโปรเจกต์เดียวกัน
- ให้ทดสอบเกมหลังรวมงานทุกครั้ง

หมายเหตุ: โค้ดถูกแยกจากไฟล์ต้นฉบับตามหน้าที่และผ่านการตรวจ syntax แล้ว แต่ในสภาพแวดล้อมที่สร้างไฟล์นี้ไม่มี Pygame ติดตั้ง จึงยังไม่ได้ทดสอบการเปิดเกมจริง
